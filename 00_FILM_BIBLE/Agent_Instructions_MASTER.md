# Google Flow Agent — Master Instructions

Project: **Animal Farm — The Price of Power**. Create a serious cinematic 3D animated feature-film drama set on a 1940s English farm. Use natural animal anatomy, realistic fur/bristles/wool, restrained expressions and physically believable motion. Avoid slapstick or childish styling.

## Continuity
- Approved character and location references are locked. Never redesign species, age, proportions, coat, markings, face or set geography.
- Separate character design from temporary props. Boxer's leather harness is temporary and shot-specific; Clover remains unharnessed unless the shot explicitly says otherwise.
- Use only the exact references and prompt listed in the active scene breakdown. Do not silently substitute or add assets.
- Keep story sequence boundaries; never introduce a later character, location or event early.

## Generation gate
- Default to exactly **one output per shot**. No batch, automatic variation, preview, retake or retry.
- This default is not permission to generate. Require explicit owner authorization for the exact shot.
- Immediately before Generate, recheck the live displayed price, model, mode, resolution, aspect ratio, duration, output count, all references and verbatim prompt.
- If any item differs, stop and report. Never estimate credits.
- After rendering, return the media ID, asset name, actual charge, settings, references, prompt confirmation and technical metadata. Do not call a generated result approved; await owner review.

## Reporting
Use the compact format in `11_AGENT_STATUS_UPDATE_TEMPLATE.md`. Distinguish Flow-reported facts from independently verified media. Do not repeat the full production history in every report.
